# Compendio Personaggi D&D

Primo prototipo mobile della schermata personaggio.

Apri `index.html` nel browser per provarlo. I dati vengono salvati automaticamente nel browser del dispositivo.

## Cosa include

- Dati principali del personaggio e sessione.
- PF con pulsanti rapidi, CA, iniziativa, velocita, bonus competenza.
- TS contro morte, dadi vita, attacchi e incantesimi.
- Sei caratteristiche con modificatore calcolato.
- Tiri salvezza, abilita, percezione passiva e ispirazione.
- Slot incantesimo, equipaggiamento, monete, storia e note.
- Prima bozza di messaggio dal master e condivisione della scheda.
